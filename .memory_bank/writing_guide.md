# Writing Guide

Memory Bank для этого репозитория пишется по следующим правилам:

- Пиши по-русски, а имена файлов, путей, переменных и команд оставляй на английском.
- Фиксируй только стабильные вещи: стиль продукта, стек, границы модулей, рабочие соглашения.
- Не копируй код в документацию, если достаточно ссылки на исходный файл.
- Пиши коротко, но так, чтобы агент мог принять решение без дополнительного поиска.
- Если есть несколько источников истины, явно называй главный.
- Каждый файл должен заканчиваться строкой с датой последнего обновления.

## Формат записи

- Заголовок с темой.
- Краткий контекст.
- Нормы и ограничения.
- Ссылки на релевантные файлы.
- Дата обновления в конце.

## Что не делать

- Не добавлять выдуманные домены и разделы "на вырост".
- Не превращать Memory Bank в копию codebase.
- Не описывать устаревшее состояние как текущее.
- Не хранить здесь пользовательские догадки без подтверждения в коде.
