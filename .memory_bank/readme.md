# Memory Bank

Краткий индекс для работы с `rezynt`.

## Что читать сначала

1. `DESIGN.md` - визуальный язык продукта, правила UI и ограничения стиля.
2. `frontend/readme.md` - карта пользовательского интерфейса и shared-слоя.
3. `backend/readme.md` - карта API, services и data layer.
4. `infra/readme.md` - landing, nginx и delivery.
5. `stack.md` - стек, версии и практические ограничения среды.
6. `writing_guide.md` - как обновлять и писать записи в Memory Bank.

## Назначение

- Хранить только то, что реально помогает быстро продолжать работу.
- Описывать текущий код, а не желаемое состояние.
- Держать ссылки на исходники вместо пересказа реализации.

## Карта файлов

- `DESIGN.md` - дизайн-система и продуктовый стиль.
- `stack.md` - технологический стек и эксплуатационные ограничения.
- `writing_guide.md` - правила написания и обновления записей.
- `frontend/readme.md` - frontend domain map.
- `backend/readme.md` - backend domain map.
- `infra/readme.md` - infra domain map.
