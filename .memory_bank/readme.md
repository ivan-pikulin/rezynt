# Memory Bank

Единая рабочая документация по Rezynt. Здесь должны жить все актуальные знания о коде, маршрутах, сервисах и инфраструктуре.

## Что читать первым

1. [`stack.md`](./stack.md) - стек, ограничения и рабочие правила.
2. [`frontend/readme.md`](./frontend/readme.md) - карта фронтенда и пользовательских потоков.
3. [`backend/readme.md`](./backend/readme.md) - карта backend, API и данных.
4. [`infra/readme.md`](./infra/readme.md) - landing, nginx и деплой.

## Доменная карта

- `frontend/` - приложение на React/Vite.
- `backend/` - FastAPI API, Celery, ORM, analysis engine.
- `infra/` - landing page, nginx и production delivery.

## Стандарт

- Один домен = один файл или папка.
- Один документ = одна тема.
- Если тема разрастается, выноси её в отдельный файл, а не расширяй без конца один документ.
- Все документы заканчиваются датой последнего обновления.
- Источник истины - код и актуальные файлы в `.memory_bank`.

## Legacy policy

- Старые README/spec/changelog-файлы из корня репозитория считаются устаревшими и должны быть удалены после миграции.
- Если в коде или документации есть расхождение, приоритет у кода и текущего Memory Bank.
